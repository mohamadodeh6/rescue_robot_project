                        Person Detection Pipeline

                            Camera Frame (640x480x4)
                                 │
                                 ▼
                            Rotate 90° + BGR Conversion
                                 │
                                 ▼
                            Resize to 320x240
                            (Speed optimization)
                                 │
                                 ▼
                        ┌─────────────────────┐
                        │   YOLOv8n Model     │
                        │   • FP16 precision  │
                        │   • Conf > 0.45     │
                        │   • Class: Person   │
                        └─────────┬───────────┘
                                  │
                                  ▼
                            Bounding Box [x1,y1,x2,y2]
                                  │
                                  ▼
                            Calculate BBox Center
                            bbox_center_x = (x1 + x2) / 2
                                  │
                                  ▼
                            Angle Offset Calculation
                            angle = (center/width - 0.5) × FOV
                                  │
                                  ▼
                            LiDAR Ray Selection
                            index = (angle + π) / (2π) × num_ranges
                                  │
                                  ▼
                            Distance = ranges[index]
                                  │
                                  ▼
                            World Coordinates Transform
                            person_x = robot_x + distance × cos(yaw + angle)
                            person_y = robot_y + distance × sin(yaw + angle)
                                  │
                                  ▼
                            Duplicate Check
                            (distance to existing < 0.6m?)
                                  │
                                  ├─ Yes → Ignore
                                  │
                                  └─ No → Log Person
                                          │
                                          ▼
                                    Save to JSON
                                    {person1: [x, y]}
